# Инструмент визуализации графа зависимостей (Вариант №13)

## 1. Общее описание
CLI-приложение для анализа и визуализации графа зависимостей пакетов формата **Java (Maven)** без использования сторонних менеджеров пакетов и библиотек получения зависимостей.

* **Этап 1:** Минимальный прототип с конфигурацией через аргументы командной строки и валидацией параметров.
* **Этап 2:** Сбор данных о прямых зависимостях заданной версии пакета из удаленного Maven-репозитория.
* **Этап 3:** Построение транзитивного графа зависимостей алгоритмом **BFS с рекурсией**, фильтрация и обработка циклов.
* **Этап 4:** Расчет и вывод топологического порядка загрузки зависимостей.
* **Этап 5:** Генерация текстового описания графа на языке диаграмм **D2**, сохранение в **PNG**-файл, вывод **ASCII-дерева** и сравнение со штатным Maven.

## 2. Описание всех функций и настроек

### Настраиваемые параметры командной строки
* `-p`, `--package` — имя анализируемого пакета.
* `-r`, `--repo` — URL репозитория Maven или путь к файлу тестового репозитория.
* `-t`, `--test-mode` — режим тестового репозитория (`true`/`false`).
* `-v`, `--version` — версия пакета.
* `-o`, `--output` — имя выходного PNG-файла с изображением графа (по умолчанию `graph.png`).
* `-a`, `--ascii-tree` — вывод дерева зависимостей в формате ASCII (`true`/`false`).
* `-f`, `--filter` — подстрока для исключения пакетов.
* `-l`, `--load-order` — вывод порядка загрузки (`true`/`false`).

### Основные функции Этапа 5 (`src/main.py`)
* `generate_d2_code(graph, root_label)` — формирует синтаксис графа на языке диаграмм D2.
* `render_d2_to_png(d2_code, output_image)` — экспортирует граф в формат PNG (через утилиту D2 или встроенный генератор).
* `print_ascii_tree(...)` — рекурсивно выводит древовидную структуру зависимостей в консоль с символами `├──` и `└──`.
