# Инструмент визуализации графа зависимостей (Вариант №13)

## 1. Общее описание
CLI-приложение для анализа и визуализации графа зависимостей пакетов (формат Java Maven) без использования сторонних менеджеров пакетов и библиотек получения зависимостей.

На **Этапе 1** реализован минимальный прототип с конфигурацией через аргументы командной строки, выводом всех настраиваемых параметров в формате `ключ=значение` и валидацией входных данных.

## 2. Описание всех функций и настроек

### Настраиваемые параметры командной строки
* `-p`, `--package` — имя анализируемого пакета (обязательный параметр, непустая строка без пробелов).
* `-r`, `--repo` — URL-адрес удаленного репозитория (`http`/`https`) или путь к существующему локальному файлу тестового репозитория (обязательный параметр).
* `-t`, `--test-mode` — режим работы с тестовым репозиторием (`true` или `false`, по умолчанию `false`).
* `-v`, `--version` — версия анализируемого пакета (обязательный параметр, допустимы буквы, цифры, `.`, `_`, `-`).
* `-o`, `--output` — имя сгенерированного файла с изображением графа с расширением `.png` (по умолчанию `graph.png`).
* `-a`, `--ascii-tree` — режим вывода зависимостей в формате ASCII-дерева (`true` или `false`, по умолчанию `false`).
* `-f`, `--filter` — подстрока для фильтрации пакетов (не должна содержать пробелов, по умолчанию пустая строка).

### Основные функции (`src/cli.py`)
* `parse_bool_param(raw_value, param_name)` — валидирует и преобразует строковый булев параметр.
* `validate_package_name(package_name)` — проверяет корректность имени пакета.
* `validate_repo_source(repo_source, test_mode)` — проверяет URL или существование файла тестового репозитория.
* `validate_version(version)` — проверяет формат версии пакета.
* `validate_output_image(output_image)` — проверяет имя файла и расширение `.png`.
* `validate_filter_substring(filter_substring)` — проверяет отсутствие пробелов в подстроке фильтрации.
* `build_config(argv)` — собирает и валидирует объект конфигурации `AppConfig`.
* `main(argv)` — точка входа в приложение, выводит конфигурацию или сообщение об ошибке.
