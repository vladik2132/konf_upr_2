# Инструмент визуализации графа зависимостей (Вариант №13)

## 1. Общее описание
CLI-приложение для анализа и визуализации графа зависимостей пакетов формата **Java (Maven)** без использования сторонних менеджеров пакетов и библиотек получения зависимостей.

* **Этап 1:** Минимальный прототип с конфигурацией через аргументы командной строки и валидацией входных параметров.
* **Этап 2:** Сбор данных о прямых зависимостях заданной версии пакета из удаленного Maven-репозитория путем загрузки и XML-парсинга `.pom`-файла.
* **Этап 3:** Построение транзитивного графа зависимостей алгоритмом **BFS с рекурсией**, фильтрация пакетов по подстроке, обработка циклических зависимостей и поддержка режима тестирования по файлу описания графа репозитория (пакеты из больших латинских букв).

## 2. Описание всех функций и настроек

### Настраиваемые параметры командной строки
* `-p`, `--package` — имя анализируемого пакета (`groupId:artifactId` для Maven или заглавные латинские буквы `A-Z` в тестовом режиме).
* `-r`, `--repo` — URL-адрес удаленного репозитория Maven или путь к файлу тестового репозитория.
* `-t`, `--test-mode` — режим работы с тестовым репозиторием (`true` или `false`, по умолчанию `false`).
* `-v`, `--version` — версия анализируемого пакета (по умолчанию `1.0.0`).
* `-o`, `--output` — имя сгенерированного файла с изображением графа с расширением `.png` (по умолчанию `graph.png`).
* `-a`, `--ascii-tree` — режим вывода зависимостей в формате ASCII-дерева (`true` или `false`, по умолчанию `false`).
* `-f`, `--filter` — подстрока для фильтрации (исключения) пакетов при анализе.

### Основные функции Этапа 3 (`src/main.py`)
* `load_test_repository(file_path)` — загружает и валидирует файл описания графа тестового репозитория, где пакеты именуются большими латинскими буквами.
* `should_skip_package(package_name, filter_substring)` — проверяет наличие запрещенной подстроки в имени пакета.
* `bfs_recursive_step(...)` — рекурсивно обходит граф зависимостей по уровням в ширину (BFS) с защитой от зацикливания.
* `build_dependency_graph(root_package, provider, filter_substring)` — формирует полный транзитивный граф зависимостей.
* `detect_cycles(graph)` — обнаруживает циклические зависимости в построенном графе.
