# Инструмент визуализации графа зависимостей (Вариант №13)

## 1. Общее описание
CLI-приложение для анализа и визуализации графа зависимостей пакетов формата **Java (Maven)** без использования сторонних менеджеров пакетов и библиотек получения зависимостей.

* **Этап 1:** Минимальный прототип с конфигурацией через аргументы командной строки и валидацией входных параметров.
* **Этап 2:** Сбор данных о прямых зависимостях заданной версии пакета из удаленного Maven-репозитория путем загрузки и XML-парсинга `.pom`-файла.
* **Этап 3:** Построение транзитивного графа зависимостей алгоритмом **BFS с рекурсией**, фильтрация пакетов по подстроке, обработка циклических зависимостей и поддержка тестового репозитория.
* **Этап 4:** Вывод на экран порядка загрузки зависимостей для заданного пакета и сравнение результатов со штатным менеджером пакетов Maven.

## 2. Описание всех функций и настроек

### Настраиваемые параметры командной строки
* `-p`, `--package` — имя анализируемого пакета (`groupId:artifactId` или `A-Z` в тестовом режиме).
* `-r`, `--repo` — URL-адрес репозитория Maven или путь к файлу тестового репозитория.
* `-t`, `--test-mode` — режим работы с тестовым репозиторием (`true` или `false`).
* `-v`, `--version` — версия анализируемого пакета (по умолчанию `1.0.0`).
* `-o`, `--output` — имя сгенерированного PNG-файла с графом (по умолчанию `graph.png`).
* `-a`, `--ascii-tree` — режим вывода зависимостей в формате ASCII-дерева (`true` или `false`).
* `-f`, `--filter` — подстрока для фильтрации (исключения) пакетов.
* `-l`, `--load-order` — режим вывода на экран порядка загрузки зависимостей (`true` или `false`, по умолчанию `true`).

### Основные функции Этапа 4 (`src/main.py`)
* `compute_load_order(graph)` — вычисляет топологический порядок загрузки пакетов (от листовых зависимостей к корневому пакету) на основе построенного BFS-графа с обработкой циклических связей.
* `print_graph_report(...)` — выводит структуру графа, найденные циклы и пронумерованный порядок загрузки пакетов.
