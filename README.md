# Инструмент визуализации графа зависимостей (Вариант №13)

## 1. Общее описание
CLI-приложение для анализа и визуализации графа зависимостей пакетов формата **Java (Maven)** без использования сторонних менеджеров пакетов и библиотек получения зависимостей.

* **Этап 1:** Минимальный прототип с конфигурацией через аргументы командной строки и валидацией входных параметров.
* **Этап 2:** Сбор данных о прямых зависимостях заданной версии пакета из удаленного Maven-репозитория путем загрузки и XML-парсинга `.pom`-файла.

## 2. Описание всех функций и настроек

### Настраиваемые параметры командной строки
* `-p`, `--package` — имя анализируемого пакета в формате `groupId:artifactId` (обязательный параметр).
* `-r`, `--repo` — URL-адрес удаленного репозитория Maven или путь к файлу тестового репозитория (обязательный параметр).
* `-t`, `--test-mode` — режим работы с тестовым репозиторием (`true` или `false`, по умолчанию `false`).
* `-v`, `--version` — версия анализируемого пакета (обязательный параметр).
* `-o`, `--output` — имя сгенерированного файла с изображением графа с расширением `.png` (по умолчанию `graph.png`).
* `-a`, `--ascii-tree` — режим вывода зависимостей в формате ASCII-дерева (`true` или `false`, по умолчанию `false`).
* `-f`, `--filter` — подстрока для фильтрации пакетов (по умолчанию пустая строка).

### Основные функции (`src/main.py`)
* `build_config(argv)` — парсит и валидирует аргументы командной строки.
* `build_pom_url(repo_url, package_name, version)` — формирует полный URL-адрес `.pom`-файла пакета по координатам Maven.
* `fetch_pom_xml(pom_url)` — загружает содержимое `.pom`-файла по протоколу HTTP/HTTPS.
* `extract_pom_properties(root, package_version)` — извлекает секцию `<properties>` для подстановки версий.
* `parse_direct_dependencies(xml_text, version)` — разбирает XML-дерево `.pom`-файла и извлекает прямые зависимости из секции `<dependencies>`.
* `get_direct_dependencies(config)` — объединяет загрузку и разбор прямых зависимостей пакета.
